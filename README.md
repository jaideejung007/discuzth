## Discuz\! คืออะไร? 🤔

**Discuz\!** คือสุดยอดเครื่องมือสำหรับสร้างเว็บไซต์ประเภท "ชุมชนออนไลน์" หรือ "เว็บบอร์ด" 👨‍👩‍👧‍👦 ช่วยให้คุณมีเว็บไซต์ที่ครบวงจรในที่เดียว ไม่ว่าจะเป็นบอร์ดพูดคุย, บทความ, หรือกิจกรรมต่าง ๆ ก็สามารถจัดการได้ง่าย ๆ ในระบบเดียวจบ\!

## ✨ มีอะไรใหม่ใน X3.5\! (ฉบับภาษาไทย)

นี่คือการอัปเกรดครั้งใหญ่ที่ทำให้ Discuz\! ทันสมัย, ปลอดภัย และใช้งานง่ายขึ้นกว่าเดิม\!

### 🚀 ทันสมัยและแรงขึ้น

  * **รองรับเทคโนโลยีใหม่:** ทำงานได้ดีบน PHP 8 และ MySQL 8
  * **รองรับ IPv6 & CDN:** พร้อมสำหรับอนาคตของอินเทอร์เน็ต และช่วยให้เว็บโหลดไวขึ้น
  * **รองรับ InnoDB:** ทำงานได้ดีกับฐานข้อมูลบนคลาวด์
  * **แรงกว่าเดิม:** ปรับปรุงประสิทธิภาพ HTTPS ให้ดีขึ้น
  * **ลาก่อน Flash:** เปลี่ยนไปใช้ HTML5 ทั้งหมดแล้ว 🎬

### 🛠️ ฟีเจอร์จัดเต็ม

  * **รองรับ Emoji\!:** ใช้ UTF8MB4 ทำให้โพสต์อิโมจิ 🤩 และอักขระพิเศษได้หลากหลายขึ้น
  * **ไม่ใช่แค่เว็บบอร์ด:** สลับเปิด/ปิดโมดูลต่าง ๆ ได้เต็มรูปแบบ ทำให้ Discuz\! เป็นได้มากกว่าเว็บบอร์ด\!
  * **โฉมใหม่ไฉไลกว่าเดิม:**
      * โหมดมือถือดีไซน์ใหม่ 📱
      * ระบบหลังบ้าน (AdminCP) ดีไซน์ใหม่ 🖥️
      * BBcode Spoiler (ปุ่มซ่อนข้อความ) รูปแบบใหม่
  * **ระบบชำระเงินใหม่:** (ยังไม่รองรับในไทย) แต่ระบบใหม่รองรับ WeChat Pay, Alipay และพร้อมให้นักพัฒนาเชื่อมต่อกับระบบอื่นได้ง่ายขึ้น

### 🇹🇭 พิเศษสำหรับคนไทย

  * **ปรับแต่งเพื่อคนไทย:** ปรับปรุงหน้าตา (UX/UI) และการจัดเรียงคำต่าง ๆ ให้เข้ากับบริบทภาษาไทย 🇹🇭
  * **ข้อมูลจังหวัด/อำเภอ/ตำบล:** อัปเดตฐานข้อมูลใหม่ล่าสุด (จาก ThepExcel ปี 2565)
  * **รายชื่อประเทศ:** อัปเดตใหม่ (จากสำนักงานราชบัณฑิตยสภา ปี 2565)
  * **ระบบค้นหาตำแหน่งจาก IP (GeoIP2):** ระบุตำแหน่งได้แม่นยำขึ้นในระดับ เขต/อำเภอ, จังหวัด และประเทศ

### 🔒 ปลอดภัยยิ่งขึ้น

  * **เข้ารหัสรหัสผ่าน:** ปรับปรุงกระบวนการเข้ารหัสให้ปลอดภัยมากขึ้น 🛡️
  * **ระบบป้องกันพื้นฐาน:** มีระบบปกป้องในตัว และรองรับการเชื่อมต่อ SMS จากผู้ให้บริการอื่น

## 📦 เริ่มต้นใช้งาน

### 1\. สำหรับการติดตั้งใหม่ (New Installation)

1.  **ดาวน์โหลด:** โหลดไฟล์ล่าสุดได้ที่นี่: [คลิกเพื่อดาวน์โหลด](https://github.com/jaideejung007/discuzth/releases/latest) (มองหาไฟล์ `Discuz_X3.5_TH_UTF8_YYYYMMDD_Rev.x.zip`)
2.  **อัปโหลด:** แตกไฟล์ .zip แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `upload` ขึ้นไปบนเซิร์ฟเวอร์ของคุณ (ใช้โปรแกรม FTP เช่น FileZilla)
      * *ไม่จำเป็นต้องอัปโหลดโฟลเดอร์ `readme` และ `utility`*
3.  **ติดตั้ง:** เปิดเบราว์เซอร์ไปที่ `https://yourdomain.com/install` แล้วทำตามขั้นตอนบนหน้าจอได้เลย\!

#### 📝 ขั้นตอนการอัปเกรด (แบบอ่าน)

ก่อนเริ่ม, นี่คือสิ่งที่คุณต้องเตรียม:
1.  **ตรวจสอบการเชื่อมต่อ UCenter:** ไปที่ `yourdomain.com/uc_server` ล็อกอิน แล้วไปที่เมนู `การเชื่อมต่อ` ต้องขึ้นสถานะสีเขียวว่า `เชื่อมต่อได้`
2.  **ดาวน์โหลดไฟล์อัปเกรด:** โหลดได้ที่โฟลเดอร์ [utility](https://github.com/jaideejung007/discuzth/tree/v3.5/utility) (หรือลิงก์นี้: [https://go.discuzth.com/dzx35-utility](https://go.discuzth.com/dzx35-utility))
3.  **ดาวน์โหลดไฟล์ Discuz! X3.5 ตัวเต็ม:** โหลดได้ที่นี่: [คลิกเพื่อดาวน์โหลด](https://github.com/jaideejung007/discuzth/releases/latest) (มองหาไฟล์ `Discuz_X3.5_TH_UTF8_YYYYMMDD_Rev.x.zip`)
4.  **🚨 สำรองข้อมูล (Backup)!!:** สำรอง *ทั้งฐานข้อมูล* และ *ไฟล์ทั้งหมด* ของคุณก่อน! นี่คือขั้นตอนที่สำคัญที่สุด ห้ามข้ามเด็ดขาดครับ

เมื่อพร้อมแล้ว ให้ทำตาม 2 ส่วนนี้ครับ:

**ส่วนที่ 1: อัปเกรด UCenter (จาก 1.6.0 เป็น 1.7.0)**

1.  **ย้ายไฟล์ UCenter เก่า:**
    * ไปที่โฟลเดอร์ 📁 `uc_server`
    * สร้างโฟลเดอร์ใหม่ชื่อ 📁 `old`
    * ย้ายไฟล์และโฟลเดอร์ *ทั้งหมด* ใน 📁 `uc_server` ไปไว้ใน 📁 `old`
    * **ยกเว้น!** ห้ามย้ายโฟลเดอร์ 📁 `data`

2.  **อัปโหลด UCenter ใหม่:**
    * จากไฟล์ Discuz! X3.5 ตัวเต็มที่คุณดาวน์โหลดมา ให้ไปที่โฟลเดอร์ `upload/uc_server`
    * อัปโหลดไฟล์และโฟลเดอร์ *ทั้งหมด* ในนั้น ขึ้นไปทับที่ 📁 `uc_server` บนเซิร์ฟเวอร์ของคุณ

3.  **เตรียมไฟล์อัปเกรด:**
    * อัปโหลดไฟล์ 📄 `update_ucenter_adult.php` (จากโฟลเดอร์ utility) ไปไว้ที่ 📁 `uc_server/install`
    * ลบไฟล์ 📄 `uc_server/data/upgrade.lock` (ถ้ามี)

4.  **รันตัวอัปเกรด UCenter:**
    * เปิดเบราว์เซอร์ไปที่ `https://yourdomain.com/uc_server/install/update_ucenter_adult.php`
    * ทำตามขั้นตอนที่ปรากฏบนหน้าจอจนเสร็จ

**ส่วนที่ 2: อัปเกรด Discuz! (จาก X3.4 เป็น X3.5)**

1.  **ย้ายไฟล์ Discuz! เก่า:**
    * กลับมาที่หน้าแรกของเว็บคุณ (โฟลเดอร์ราก)
    * สร้างโฟลเดอร์ใหม่ชื่อ 📁 `old` (คนละตัวกับใน `uc_server` นะครับ)
    * ย้ายไฟล์และโฟลเดอร์ *ทั้งหมด* ไปไว้ใน 📁 `old`
    * **ยกเว้น!** ห้ามย้าย 3 โฟลเดอร์นี้: 📁 `config`, 📁 `data` และ 📁 `uc_server`

2.  **อัปโหลด Discuz! ใหม่:**
    * จากไฟล์ Discuz! X3.5 ตัวเต็มที่คุณดาวน์โหลดมา ให้ไปที่โฟลเดอร์ `upload`
    * อัปโหลดไฟล์และโฟลเดอร์ *ทั้งหมด* ในนั้น (ยกเว้นโฟลเดอร์ 📁 `uc_server` เพราะเราทำไปแล้ว) ขึ้นไปทับที่โฟลเดอร์รากของเว็บคุณ

3.  **ย้ายปลั๊กอินและธีมเก่ากลับมา:**
    * **ปลั๊กอิน:** ย้ายโฟลเดอร์ปลั๊กอิน *ที่คุณติดตั้งเอง* จาก 📁 `old/source/plugin` กลับมาไว้ที่ 📁 `source/plugin`
    * **ธีม/เทมเพลท:** ย้ายโฟลเดอร์ธีม *ที่คุณติดตั้งเอง* จาก 📁 `old/template` กลับมาไว้ที่ 📁 `template` (ห้ามย้ายโฟลเดอร์ `default`)

4.  **เตรียมไฟล์อัปเกรด:**
    * อัปโหลดไฟล์ 📄 `update_adult.php` (จากโฟลเดอร์ utility) ไปไว้ที่ 📁 `install`
    * ลบไฟล์ 📄 `data/update.lock` (ถ้ามี)

5.  **รันตัวอัปเกรด Discuz!:**
    * เปิดเบราว์เซอร์ไปที่ `https://yourdomain.com/install/update_adult.php`
    * ทำตามขั้นตอนที่ปรากฏบนหน้าจอจนเสร็จ

### 3. ส่วนเสริม: 📝 วิธีการอัปเดตไฟล์แพทช์ย่อย (Patch/Rev.)

หลังจากที่คุณอัปเกรดเป็น X3.5 แล้ว หรือใช้งานไประยะหนึ่ง อาจมี "แพทช์" (Patch) หรือ "Rev." (Revision) ที่เป็นเวอร์ชันย่อย ๆ ออกมาเพื่อแก้ไขข้อบกพร่องหรือเพิ่มประสิทธิภาพ

นี่คือวิธีอัปเดตแพทช์ย่อยเหล่านั้นครับ:

#### 🚨 กฎเหล็ก: ต้องอัปเดตตามลำดับ ห้ามข้ามเด็ดขาด!

* **หลักการ:** คุณต้องอัปเดตเรียงลำดับทีละขั้น เช่น ถ้าคุณใช้ `Rev.2` อยู่ คุณต้องอัปเดตเป็น `Rev.3` ก่อน แล้วค่อยไป `Rev.4` (ห้ามข้ามจาก `Rev.2` ไป `Rev.4` เลย)
* **ทางลัด ⚡️ (สำหรับคนตกรุ่นนาน):** หากคุณใช้ Rev. เก่ามาก ๆ (เช่น `Rev.1`) ทีมงานอาจมี "ไฟล์แพทช์สะสม" (เช่น `3.5_R..._Rev.1-5.zip`) ให้บริการ ซึ่งจะช่วยให้อัปเดตทีเดียวไปยัง Rev. ล่าสุด (ณ ขณะนั้น) ได้เลย

#### 🛠️ ขั้นตอนการอัปเดตแพทช์ (ตัวอย่าง: จาก Rev.3 ไป Rev.4)

1.  **ตรวจสอบเวอร์ชันปัจจุบัน:**
    * เข้าสู่ระบบหลังบ้าน (AdminCP) ที่ `yourwebsite.com/admin.php`
    * ไปที่เมนู `หน้าแรก` --> `หน้าแรก AdminCP`
    * ในส่วน "ข้อมูลระบบ" ให้มองหา "เวอร์ชันภาษาไทย" (ในตัวอย่างนี้, คุณจะเห็นว่าเป็น `Rev.3`)

2.  **ดาวน์โหลดแพทช์:**
    * ที่หน้าเดิม, คลิกที่ข้อความสีแดง "ดาวน์โหลดไฟล์แพตช์" (แล้วเลือกหาไฟล์ที่อัปเดตจาก Rev.3-4, เช่น `...Rev.3-4.zip`)
    * เมื่อดาวน์โหลดเสร็จแล้ว ให้แตกไฟล์ .zip ให้เรียบร้อย

3.  **อัปโหลดไฟล์:**
    * ใช้โปรแกรม FTP (เช่น FileZilla) อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจากแพทช์ที่คุณเพิ่งแตกไฟล์ ขึ้นไป *ทับที่เดิม* บนเซิร์ฟเวอร์
    * (ถ้าโปรแกรม FTP ถามให้เขียนทับไฟล์หรือไม่ ให้ตอบ "ใช่" หรือ "Overwrite" ได้เลย)

4.  **ล้างแคช (สำคัญมาก!):**
    * กลับไปที่ AdminCP
    * ไปที่เมนู `เครื่องมือ` --> `อัปเดตแคช`
    * ติ๊กถูก ✅ ให้ครบทุกช่อง แล้วกดปุ่ม `ตกลง`

5.  **ยืนยันเวอร์ชัน:**
    * กลับไปที่ `หน้าแรก` --> `หน้าแรก AdminCP` อีกครั้ง
    * กดปุ่ม `[ เรียกข้อมูลใหม่ ]`
    * คุณจะเห็นว่า "เวอร์ชันภาษาไทย" เปลี่ยนเป็น `Rev.4` แล้ว! 🥳

#### ⚠️ หมายเหตุพิเศษ: สำหรับผู้ที่อัปเดตจาก Rev.1-3 มาเป็น Rev.4 เท่านั้น

* หลังจากอัปเดตแพทช์เป็น Rev.4 เสร็จแล้ว ให้คุณรันไฟล์ 📄 `fix_country_data.php` (โดยพิมพ์ URL: `yourwebsite.com/fix_country_data.php`)
* **ทำไม?** -> เพื่อแก้ไขปัญหาที่ผู้ใช้งานไม่สามารถแก้ไขข้อมูล "ประเทศ, จังหวัด, อำเภอ, ตำบล" ในหน้าโปรไฟล์ของตัวเองได้ครับ
