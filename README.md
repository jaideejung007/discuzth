## 1. 🚀 แนะนำ Discuz! TH X5.0

**Discuz!** คือสุดยอดเครื่องมือสำหรับสร้างเว็บไซต์ประเภท "ชุมชนออนไลน์" หรือ "เว็บบอร์ด" ที่ช่วยให้คุณมีเว็บไซต์ครบวงจรในที่เดียว 

การก้าวเข้าสู่ **X5.0** คือการเปลี่ยนแปลงครั้งยิ่งใหญ่ที่สุด! ระบบถูกสร้างขึ้นใหม่บนโครงสร้าง **Kernel MitFrame®** ซึ่งผสมผสานความเป็นคอมมูนิตี้และเฟรมเวิร์กเข้าไว้ด้วยกัน เปิดกว้าง ไร้ข้อจำกัด และทรงพลังกว่าที่เคย พร้อมกันนี้เรายังได้ปรับปรุงฟีเจอร์พิเศษมากมายเพื่อชาวไทยโดยเฉพาะ ไม่ว่าจะเป็น:
* 🌍 **ข้อมูลตำแหน่งภูมิศาสตร์ (IP Geolocation):** เราใช้บริการของ GeoLite2-City.mmdb พร้อมทั้งแปลภาษาไทยให้พร้อม เช่น "ไทย, กรุงเทพมหานคร"
* 🇹🇭 **ภาษาไทยสมบูรณ์แบบ:** ปรับ/สลับตำแหน่งข้อความในระบบต่าง ๆ ให้เข้ากับบริบทภาษาไทยมากที่สุด
* 🏘️ **ข้อมูลที่อยู่ละเอียด:** เพิ่ม "ชื่อหมู่บ้าน" เข้ามาให้ (จากปกติที่มีแค่ จังหวัด อำเภอ ตำบล)
* 🔄 **ระบบแพตช์ไทย:** ฟีเจอร์ "แพตช์อัปเกรด" ถูกเปลี่ยนมาใช้เซิร์ฟเวอร์ของไทย พร้อมภาษาไทยแล้ว เมื่อมีเวอร์ชันใหม่สามารถดาวน์โหลดและอัปเกรดได้ทันทีที่ AdminCP
* 🎨 **ดีไซน์เพื่อคนไทย:** ออกแบบและแปลภาษาไทย "ตราประทับกระทู้" (สแตมป์) ใหม่ยกชุด เช่น คัดสรร, ติดเทรนด์, ภาพสวย, คุณภาพคับแก้ว รับประกันความสวยงาม
* 📏 **ปรับปรุงตรรกะการนับอักขระภาษาไทย:** แก้ไขระบบนับและตัดคำจากเดิมที่อิงภาษาจีนให้รองรับภาษาไทย 100% ปลดล็อกการตั้งชื่อกระทู้ได้เต็ม 255 ตัวอักษรจริง ๆ และขยายขีดจำกัดชื่อเว็บบอร์ดเป็น 150 ตัวอักษร (จาก 50) หมดปัญหาระบบเตือนข้อความยาวเกิน
* 📺 **รองรับลิงก์ YouTube ล่าสุด:** อัปเกรดระบบวิเคราะห์ลิงก์และดึงภาพ Thumbnail ของ YouTube ให้ทำงานได้รวดเร็วและรองรับรูปแบบ URL ในปัจจุบันได้อย่างสมบูรณ์แบบ
* 📱 **รองรับเบอร์โทรศัพท์ไทย:** ปรับปรุงระบบตรวจสอบความถูกต้องของการกรอกเบอร์โทรศัพท์และเบอร์มือถือในหน้าโปรไฟล์ ให้รองรับรูปแบบและรหัสหมายเลขของประเทศไทยได้อย่างแม่นยำ
* 🔓 **อิสระในการปรับแต่ง:** ปลดล็อกระบบเกี่ยวกับดาวน์โหลด/ติดตั้ง/ถอนการติดตั้งของปลั๊กอินและเทมเพลตจาก Dismall App Center และฟีเจอร์อื่นๆ อีกนับไม่ถ้วน

## 2. ✨ สิ่งที่ควรรู้ & ฟีเจอร์เด่นในระบบ X5.0

เพื่อให้การใช้งานและอัปเกรดเป็นไปอย่างราบรื่น เว็บมาสเตอร์ควรเตรียมตัวดังนี้:

* 🛠️ **ความต้องการของระบบ (Environment Requirements):**
    * **PHP:** ต้องเป็นเวอร์ชัน **8.0 ขึ้นไป** เท่านั้น (รองรับจนถึง PHP 8.4)
    * **MySQL:** แนะนำเวอร์ชัน **5.7 ขึ้นไป** หรือ 8.0 เพื่อประสิทธิภาพสูงสุด
    * **Nginx:** แนะนำให้ใช้เวอร์ชันล่าสุดเพื่อความปลอดภัย
    * **Extensions:** ติดตั้ง `PHP zip`, `opcache`, และ `redis` ไว้ด้วย
* 📦 **ระบบการอัปเดตแบบใหม่ (No More Manual Patches!):** ตั้งแต่ X5 เป็นต้นไป จะไม่มีการปล่อยไฟล์ Patch แยกให้ดาวน์โหลดข้างนอก คุณสามารถกดอัปเดตระบบได้โดยตรงผ่าน **"ศูนย์ควบคุม (AdminCP)"** ในเมนู "Update Patch"
* 🛡️ **ฟีเจอร์ความปลอดภัยและประสิทธิภาพ:**
    * **Admin Security:** เพิ่มระบบ Login หลังบ้านด้วยการยืนยันตัวตนชั้นที่สอง (Secondary Verification)
    * **Multi-Account:** สามารถล็อกอินบัญชีหน้าเว็บและหลังบ้านพร้อมกันคนละ ID ได้แล้ว
    * **Speed Up:** รองรับระบบ **Preload** ใน PHP เพื่อให้หน้าเว็บโหลดเร็วขึ้น
    * **Database:** สามารถเลือกเก็บ Log ในรูปแบบไฟล์แทนฐานข้อมูลได้ เพื่อไม่ให้ฐานข้อมูลบวมเร็วเกินไป

## 4. 📦 การเริ่มต้นใช้งาน (ติดตั้ง & อัปเกรด)

### 1. การติดตั้งใหม่ (New Installation)

1.  **ดาวน์โหลด:** โหลดไฟล์ล่าสุดได้ที่หน้า Releases (มองหาไฟล์ `Discuz_X5.0_TH_...zip`)
2.  **อัปโหลด:** แตกไฟล์ .zip แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `upload` ขึ้นไปบนเซิร์ฟเวอร์ของคุณ (ใช้โปรแกรม FTP เช่น FileZilla)
3.  **ติดตั้ง:** เปิดเบราว์เซอร์ไปที่ `https://yourdomain.com/install` แล้วทำตามขั้นตอนบนหน้าจอได้เลย

👉 [อ่านเพิ่มเติมที่นี่](https://www.discuzth.com/thread-5-1-1.html)

### 2. การอัปเกรด (Upgrade)

การอัปเกรดจาก X3.5 มาเป็น X5.0 กรุณาทำตามขั้นตอนอย่างระมัดระวังดังนี้:

1.  ระบบ Discuz! เดิมของคุณต้องเป็นเวอร์ชัน **X3.5 เท่านั้น** หากเป็นเวอร์ชันเก่ากว่านี้ กรุณาอัปเกรดให้เป็น X3.5 ก่อน
2.  ตรวจสอบให้แน่ใจว่า UCenter และ Discuz! ติดตั้งอยู่ในฐานข้อมูล (Database) เดียวกัน
3.  🚨 **สำรองข้อมูล (Backup)** ฐานข้อมูลและไฟล์ระบบทั้งหมดให้เรียบร้อย จากนั้นคัดลอกไฟล์ของเวอร์ชันเก่าไปเก็บไว้ที่โฟลเดอร์อื่น
4.  คัดลอกไฟล์ตั้งค่าของเวอร์ชันเก่า ได้แก่ **config/config_global.php** และ **config/config_ucenter.php** นำมาวางในโฟลเดอร์ **config/** ของเวอร์ชันใหม่
5.  คลิกปุ่ม "ขั้นตอนต่อไป" เพื่อเริ่มการอัปเกรด
6.  เมื่ออัปเกรดเสร็จแล้ว คุณสามารถเลือกคัดลอกปลั๊กอิน (ในโฟลเดอร์ **source/plugin/**) และไฟล์เทมเพลต (ในโฟลเดอร์ **template/**) จากเวอร์ชันเก่ามาใส่ในเวอร์ชันใหม่ได้ **(คำเตือน: ห้ามคัดลอกโฟลเดอร์ template/default/ เด็ดขาด)**
7.  สำหรับไฟล์แนบใน **data/attachment/** และข้อมูลอื่น ๆ ในโฟลเดอร์ **data/** ให้คัดลอกมาเท่าที่จำเป็น หากปลั๊กอินเดิมมีการเรียกใช้ไฟล์ในโฟลเดอร์อื่น กรุณาสอบถามนักพัฒนาปลั๊กอินนั้นๆ ก่อนทำการคัดลอก
